Comment "LINE" for the checklist on what a real sample looks like. Two traders start the same week with the same method — watch what four weeks do to each of them.

Both lose in week one, because any method loses often. One starts looking for a better one. By week four the first has run four methods and the second has run one, four times longer. Neither has had a good week yet, but only one has enough trades to know anything.

THE LINE — the threshold is set before the first trade, and new ideas get a date, not a veto.
